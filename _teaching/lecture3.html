A. Dictionaries in Python

Dictionaries are somewhat like lists, but denoted by alphanumeric keys rather than integer indices.

# Create a dictionary of planetary radii (km)
solar_planets = {
    'Mercury': 2440.0, 
    'Venus': 6052.1, 
    'Earth': 6371.5, 
    'Mars': 3389.2
}

# Accessing data
print(solar_planets['Venus']) # Output: 6052.1

# Adding new data
solar_planets['Uranus'] = 25362.0

B. Program Control (If-Else)

Python uses indentation to define code blocks. This makes the code readable and is a distinctive feature of the language.

if exam >= 90.0:
    Grade = 'A'
elif exam >= 80.0:
    Grade = 'B'
else:
    Grade = 'Fail'

C. While and For Loops

A While loop executes as long as a condition is True, while a For loop steps through a list or dictionary.

Putting it All Together: Habitability Study

In this example, we iterate through a dictionary of temperatures and use logic to determine if a planet is "habitable" (-100°C to 100°C).

# Temperatures in Kelvin
surface_temps = {'Earth': 288.5, 'Mars': 210.2, 'Jupiter': 110.0}

for key in surface_temps.keys():
    temperature = surface_temps[key] - 273.1 # Convert to Celsius
 
    if (temperature <= 100) and (temperature >= -100):
        # Using round() to keep one decimal place
        print('Planet', key, 'is habitable at', round(temperature, 1), '°C')
